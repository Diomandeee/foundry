# 🌌 Spatial Git v21

Navigate code history through 3D space — now with **Commit Symphony Orchestra** and **Code Crystallography**. Hear your repo's history as a musical performance, and discover the hidden crystal structures in your co-change patterns.

## What's New in v21

### 🎵 Commit Symphony Orchestra (`9` key)
- **Branch-as-instrument** — Each branch becomes an orchestral section (Strings, Brass, Woodwinds, Percussion, etc.)
- **Commit-as-note** — Message length → pitch (pentatonic scale), file count → volume, time-of-day → duration
- **Semicircular stage** — Sections arranged in a concert hall semicircle with podiums
- **Play History** — Hit play to hear your entire commit history as a symphony
- **Live conductor** — Rotating batons and a central conductor podium
- **Audio visualizer** — Real-time frequency bars in the panel
- **Web Audio API** — Actual synthesized sound with vibrato and envelope shaping
- **Night commits** — Commits made late at night play as longer, more contemplative notes

### 🧊 Code Crystallography (`0` key)
- **Co-change analysis** — Files that are modified together form crystal bonds
- **4 crystal types** — 💎 Perfect (low variance, high strength), 🔷 Polycrystalline (moderate), 🟠 Amorphous (chaotic), 💥 Fractured (weak)
- **Geometric mapping** — Perfect=Octahedron, Poly=Dodecahedron, Amorphous=Icosahedron, Fractured=Tetrahedron
- **Lattice nodes** — Each file is a node sphere orbiting the crystal body
- **Bond lines** — Co-change relationships shown as crystal bonds with opacity = strength
- **Stability score** — Each crystal cluster rated 0-100% stability
- **Inner cores** — Denser inner structures for more stable crystals
- **Rotation dynamics** — Stable crystals rotate slow and uniform; chaotic ones jitter

## Usage

1. Generate git history JSON:
   ```bash
   ./git-to-json.sh /path/to/your/repo > git-history.json
   ```

2. Open `index.html` in a browser

3. Navigate with WASD + mouse, explore with feature toggles

## Tech Stack

- Three.js + ES modules (no build step)
- WebXR for VR support
- UnrealBloomPass for glow effects
- Web Audio API for sonification
- Pure shell script for git extraction
