# Local durable API contract

Import `DurableAuthority` (and re-exported types) from `authority.ts`. Constructor takes `(TransactionPort, DurableAuthorityOptions)`. The host, not clients, fixes environment, authorityId, issuer identity/key and artifact reader. Authority IDs permit the 64-character workerd hex ID. `expectedEpoch` is REQUIRED in every trusted context. Only `snapshot()` is a host-local context-free API; it returns `.epoch`, `.meta`, workers, workloads, safe leases, reservations and receipts after expiry sweep.

- `execute(context, {operation, key, body})`: synchronous `{ok:true,...}` or `{ok:false,code}`. Invalid schemas throw before starting a command transaction; unexpected storage errors throw and roll back. See `contracts.ts` for exact required fields, with unknown fields rejected.
- `verifyAndFinalize(context, {key,leaseId,epoch,generation,incarnation})`: async, trusted verifier role only. Reader receives `(artifactRef,maxBytes)` and MUST independently authorize immutable content; the core bounds bytes, hashes actual content, then rechecks SQL fences in a new synchronous transaction. No client receipt/finalize route exists.
- Claim returns `.lease` with `id`, alias `leaseId`, `epoch`, `generation`, `incarnation`, `capability`, `issued_ms`, `expires_ms`, `cap_ms`, `sequence`, and IDs in snake_case. Renewal returns `.expiresAt` (milliseconds). Stage returns `.verificationDeadline`. Verify returns `.receipt` with SQL-shaped immutable receipt fields. No bearer is stored in command responses or events. Capabilities are HMAC scoped to environment/authority/issuer/lease/epoch/generation/incarnation/worker/issue/lifetime. Issuer key remains trusted host configuration, bound by a keyed check on reopen.
- Quota must exist for submitter principal BEFORE submit. `setQuota` is owner-only, active workload admission cap plus general class policy. It does not implement weighted fair scheduling, per-principal CPU budgets or billing. Claim is an executor request for an explicit feasible candidate, with persisted `vector-exclusive-v1` candidate/resource/rejection facts (128-worker/64-device bounds), not an optimal fleet scheduler.
- `readOutbox {after,limit}` requires `after` equal to the acknowledged prefix; `.events` contains ordered seq/epoch/version/actor/reason/historical payload and `.through`. `ackOutbox {through}` can acknowledge only a delivered contiguous prefix. Use a fresh command key for a fresh poll; same key replays its original batch. A single trusted projection stream is supported.
- Normal restart retains epoch and monotonic server clock. `bumpEpoch {expectedEpoch}` fences physical capacity and increments epoch; refresh context from snapshot afterward. Old-epoch requests fail before replay. Issuer key rotation is deliberately unsupported; wrong key/namespace/schema binding fails constructor.
- Expiry, cancel, requeue, recovery and successful finalization quarantine physical reservations and fence worker incarnation; only trusted owner `reconcileStop` releases CPU/RAM/devices after independently proven stop. Successful finalization fences all remaining attempts on that worker conservatively. No process stop, sandbox or network authentication is claimed.

Only files within this durable directory are owned by this lane. Node SQLite tests are focused adapter evidence, not Cloudflare proof. Workerd wrapper/runtime tests belong to parent. No deployment was performed.

Artifact reader exceptions return `artifact-unavailable` without persisting a verification command response; retry the same key after a transient failure. Oversize/invalid reader results persist `artifact-too-large`. Only the reader await is caught; SQL and projection faults propagate and roll back the command transaction.

After successful finalization fences the worker, `lease-succeeded` carries the winning lease, receipt, quarantined reservation and device reservations. Trusted stop reconciliation emits `reservation-released` for each affected reservation, keyed by stable lease ID, with released reservation and device rows, followed by `worker-reconciled`. These historical facts remain immutable.

The optional artifact reader receives a third `{leaseId}` scope argument derived by the core, not the client-supplied artifact reference. A production adapter must independently bind its immutable metadata to that lease. The compute Worker adapter enforces this against its sealed SQL byte table; older local fixtures may ignore the third argument and are not authorization adapters.
